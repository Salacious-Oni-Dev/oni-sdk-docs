# Changelog

Notable changes to this repository, newest first. All SDK repositories share one version
number per release; see [Compatibility](https://github.com/Salacious-Oni-Dev/oni-sdk-docs/blob/main/guides/compatibility.md).

## Unreleased

- New: the [Project Navigator](https://salacious-oni-dev.github.io/oni-sdk-docs/navigator/navigator.html)
  (`navigator/`), a page listing every simulation system the game has and the SDK adds, the
  machines whose fixed recipes hide physics, and which elements exist. The README links it.

## 0.1.0-alpha.2 (2026-10-12)

*Oxygen Not Included: now with actual reasons for the oxygen to be not included.*

- What comes next (`NEXT-ALPHA.md`) now opens with Alpha 2: what it contains, its known
  limitations, a Preview of work built in development but not in this release (with videos and
  screenshots attached to the release), and the plan further out.
- Mod 5, Automation / IC10, is in Alpha 2: its own section in What comes next, its known
  limitations, and the COMPLIANCE page's note on its IC10 interpreter and art.
- Release cadence: a trial of about ten days between releases. The interval is not a promise.
- How a candidate is checked now names the one Alpha 2 change to the game's own behaviour, and
  says where the checks run.
- New: Art wanted (`ART-WANTED.md`), a running list of the building animations that are needed.
- New: an Idea request issue form, and a Suggesting an idea section.
- The README gains the project slogan, an Alpha 2 section near the top, and a short How it is
  checked section.
- Compatibility: the release table lists 0.1.0-alpha.1.1 and 0.1.0-alpha.2. Writing a mod and
  Installing link the Alpha 2 references.

## 0.1.0-alpha.1 (2026-10-01)

First public release.

- Guides: Getting started, Installing and removing, Compatibility, Writing a mod, and
  Visualizing the simulation.
- Installing and removing covers the three ways to get the simulation library: from the
  framework mod, with the release zip's installer, or by hand.
- What comes next (`NEXT-ALPHA.md`): what Alpha 1 contains, how releases work, and the
  candidates for the next alpha.
- The README is the SDK's front page, with a table of every SDK repository.
- Contributing guidelines and issue forms for bug reports and feature or API requests.
