# Changelog

Notable changes to this repository, newest first. All SDK repositories share one version
number per release; see [Compatibility](https://github.com/Salacious-Oni-Dev/oni-sdk-docs/blob/main/guides/compatibility.md).

## 0.1.0-alpha.1 (2026-10-01)

First public release.

- Guides: Getting started, Installing and removing, Compatibility, Writing a mod, and
  Visualizing the simulation.
- Installing and removing covers the three ways to get the simulation library: from the
  framework mod, with the release zip's installer, or by hand.
- What comes next (`NEXT-ALPHA.md`): what Alpha 1 contains, how releases work, and the
  candidates for the next alpha.
- The README is the SDK's front page, with a table of every SDK repository.
- Contributing guidelines and issue forms for bug reports and feature or API requests.
